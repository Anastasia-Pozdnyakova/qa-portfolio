# Тест-кейсы для /api/auth

## Базовые данные
- **Документация:** `https://restapi.tech`
- **Эндпоинт 1:** `/auth/authorize`
- **Headers:** `Accept: application/json`

- **Эндпоинт 2:** `/auth/me`
- **Headers:** `Accept: application/json`, `x-token: auth_token`

---

## POST /api/auth/authorize

### TC-32: Успешная регистрация пользователя
- **Тело запроса:** `{"login": "user_{timestamp}", "password": "qwerty12345", "timeout": 360}`
- **Ожидаемый статус:** 200
- **Ожидаемый результат:** `token` (строка, не пустая)

### TC-33: Регистрация с невалидным паролем
- **Тело запроса:** `{"login": string, "password": "qwerty1", "timeout": integer}`
- **Ожидаемый статус:** 403
- **Ожидаемый результат:** `detail.reason`

### TC-34: Регистрация с логином < 3 символов
- **Тело запроса:** `{"login": "Us", "password": "qwerty12345", "timeout": integer}`
- **Ожидаемый статус:** 422
- **Ожидаемый результат:** `detail` массив с ошибкой

### TC-35: Регистрация без поля password
- **Тело запроса:** `{"login": string, "timeout": integer}`
- **Ожидаемый статус:** 422
- **Ожидаемый результат:** `detail` массив с ошибкой

---

## GET /api/auth/me

### TC-36: Успешное получение информации о пользователе
- **Pre-request:** Зарегистровать пользователя и сохранить токен из ответа в переменную `auth_token`
- **Ожидаемый статус:** 201
- **Headers:** `x-token: {{auth_token}}`
- **Ожидаемый статус:** 200
- **Обязательные поля в ответе:** `user_name`, `email_address`, `valid_till`

### TC-37: Без заголовка x-token
- **Headers:** без `x-token`
- **Ожидаемый статус:** 401
- **Ожидаемый результат:** `detail.reason`

### TC-38: С невалидным токеном
- **Headers:** `x-token: invalid_token_123`
- **Ожидаемый статус:** 403
- **Ожидаемый результат:** `detail.reason`

---

## Дополнительно

### TC-39: Проверка истечения токена (timeout)
- **Тело запроса:** `{"login": "user_{timestamp}", "password": "qwerty12345", "timeout": 1}`
- **Ожидаемый статус:** 200 (токен получен)
- **Дополнительно:** Подождать 2 секунды
- **Запрос к /me** с этим токеном
- **Ожидаемый статус:** 403
- **Ожидаемый результат:** `detail.reason` содержит `"incorrect"` или `"expired"`
