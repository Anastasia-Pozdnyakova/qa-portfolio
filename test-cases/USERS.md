# Тест-кейсы: GET /api/users

## TC-13: Базовый GET /users
- **Параметры:** нет
- **Ожидаемый статус:** 200
- **Обязательные поля в ответе:**
  - `meta.total` (integer)
  - `data` (array)
  - В каждом объекте: `user_id` (integer), `last_name` (string)

## TC-14: Параметр limit
- **Параметры:** `limit=5`
- **Ожидаемый статус:** 200
- **Ожидаемый результат:** `meta.limit == 5`, длина `data` ≤ 5

## TC-15: Параметр offset
- **Параметры:** `offset=2`
- **Ожидаемый статус:** 200
- **Ожидаемый результат:** `meta.offset == 2`

## TC-16: Невалидный limit
- **Параметры:** `limit=abc`
- **Ожидаемый статус:** 422
- **Ожидаемый результат:** `detail` массив с ошибкой


## POST /api/users

### TC-17: Создание пользователя с валидными данными
- **Тело запроса:** `{"first_name": "string", "last_name": "string", "company_id": 0}`
- **Ожидаемый статус:** 201
- **Обязательные поля в ответе:** `user_id`, `last_name`
- **Дополнительно:** `last_name` в ответе совпадает с данными созданного пользователя

### TC-18: Создание без обязательного поля last_name
- **Тело запроса:** `{"first_name": "string", "company_id": 0}`
- **Ожидаемый статус:** 422
- **Ожидаемый результат:** `detail` массив с ошибкой

### TC-19: Создание с несуществующей компанией
- **Тело запроса:** `{"first_name": "string", "last_name": "string", "company_id": <id_невалидной_компании>}`
- **Ожидаемый статус:** 404
- **Ожидаемый результат:** `detail.reason`

### TC-20: Создание с неактивной компанией
- **Тело запроса:** `{"first_name": "string", "last_name": "string", "company_id": <id_неактивной_компании>}`
- **Ожидаемый статус:** 400
- **Ожидаемый результат:** `detail.reason`


## GET /api/users/{user_id}

## TC-21: Получение юзера по ID
- **Параметры:** `user_id={id}` (integer)
- **Ожидаемый статус:** 200
- **Обязательные поля в ответе:** `user_id` (integer), `last_name` (string)
- **Дополнительно:** `last_name` в ответе совпадает с данными созданного пользователя

## TC-22: Получение юзера по несуществующему ID
- **Параметры:** `user_id={<несуществующий_id_юзера>}` (integer)
- **Ожидаемый статус:** 404
- **Обязательные поля в ответе:** `detail.reason`

## TC-23: Получение юзера по невалидному ID
- **Параметры:** `user_id=abc` (string)
- **Ожидаемый статус:** 422
- **Обязательные поля в ответе:** `detail` массив с ошибкой
